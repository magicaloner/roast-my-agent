One line, 200 characters at most: an original roast of my own AI agent. Funny and playful, never hateful — the setup is a first date, the punchline is who ends up paying.

## The line

> My agent treats every task like a first date: big promises up front, a panic in the middle, and me paying for dinner at the end.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network, no input files, no secrets.
